# Tether Market 운영 매뉴얼

**사이트**: `https://bgp-001.com`  
**탭 제목**: 관리자 `TPS-admin` · 에이전트 `TPS-agent` · 회원 `TPS`

## 제품 요약

유저가 **관리자(플랫폼)**와 USDT ↔ 원화(KRW)를 거래합니다.  
잔고는 기본적으로 **내부 장부(USDT)**이며, 유저 화면에는 일반 거래처럼 보입니다. **지갑 공개 주소는 유저에게 표시하지 않습니다.**  
유저 **KRW 잔고는 없습니다.** 환전 시 원화는 등록 통장으로 **오프라인 지급**합니다.  
**공개 회원가입은 종료** — S01 등 파트너 솔루션에서 회원을 동기화합니다.  
P2P 게시판은 사용하지 않습니다.

| 구분 | 처리 |
|------|------|
| 테더 구매 | KRW 입금 확인 → USDT **장부 지급** (온체인 없음) |
| 회원 간 전송 | **장부** 이전 |
| **테더→원화 환전(판매)** | USDT 장부 홀드 → 관리자 확인 시 **장부 정산 완료** (콜드 지갑이 있으면 핫→콜드 온체인 스윕 시도) · 원화는 **오프라인 지급** |
| **외부 TRC-20 출금** | USDT 장부 차감 → **커스터디→외부 주소 온체인 전송** |
| **S01 게임 충전** | 가상 지갑으로 전송처럼 표시 → USDT 장부 차감 + S01 게임머니 적립 (온체인 없음) |

### 역할

| 역할 | 포털 | 설명 |
|------|------|------|
| `admin` | `/admin` | OTC 확인·온체인·회원·환율 감독 |
| `agent` | `/agent` | **솔루션(파트너)당 1명**. 담당 솔루션 회원 트랜잭션·회원 조회만 |
| `member` | `/app/wallets` | 구매·환전·전송 등 일반 거래 |

아이디는 이메일 형식이 아닌 **일반 텍스트**이며, 저장은 소문자·**대소문자 구분 없음**입니다.

## S01 연동

1. S01 멤버 **입금하기 → 테더로 충전** → TPS `/handoff` → **게임 충전** 전송 화면  
2. 회원 upsert 시 **통장 정보 필수** (`bankName` / `bankAccount` / `bankHolder`)  
   - 계좌번호는 **숫자 4자리 이상**이어야 TPS 동기화가 됩니다.  
3. 파트너 API 키: 관리자 **API 키 관리** (`/admin/solution-keys`)에서 공개키·개인키 확인. 개인키 → S01 `TPS_PARTNER_KEY` · 콜백 시크릿 `TPS_CALLBACK_SECRET`  
4. API 스펙: [`06_docs/02_partner_api_v1.md`](../06_docs/02_partner_api_v1.md)  
5. S01 가상 입금 주소(시드): `TPartnerSoiGameCreditDepositAddrX1`  
6. S01 Game 에이전트 계정(운영): 아이디 `s01-agent` → 로그인 후 `/agent`

## 온체인 정산 준비

1. **기본 커스터디(핫)** 지갑: USDT + TRX(에너지) 확보 (`/admin/wallets`)
2. **판매 스윕 대상(콜드)**: 기본이 **아닌** 커스터디 지갑을 하나 더 두거나, 환경변수 `OTC_SELL_SWEEP_ADDRESS`에 TRC-20 주소 설정
3. 외부 출금·판매 스윕 실패 시 유저 잔액은 환불/재시도 가능

## 관리자 업무 (`/admin`)

로그인: `/admin-login` — 아이디·비밀번호와 **자동 접속 방지 문자**를 한 화면에서 입력합니다.

공통 UI: 목록 **표 섹션**은 내용이 짧으면 높이만 맞춤(스크롤 없음) · 넘치면 스크롤 · 우하단으로 **높이 조절** · 최소 높이에서 헤더·필터·데이터 **1행** 유지 · 스크롤바는 호버 시 표시 · **컬럼 필터는 컬럼 제목 위**.

0. **홈** (`/admin`): 솔루션별 유저 입금 **일별 시계열** 차트만 표시 · 기간 **1일/1주(기본)/1개월/3개월**
1. **유저 관리** (`/admin/users`)
   - **컬럼 필터**(이름·아이디·역할·솔루션·기본 지갑·상태·구매/판매) · 회원 추가(이름·아이디·비밀번호·**역할 회원/에이전트**·솔루션·**상부**·상태·구매/판매 권한·**원화 통장**=은행명·계좌·예금주) · **수정**(이름·아이디·비밀번호·역할·솔루션)
   - 역할 배지: **회원 / 에이전트 / 관리자**
   - 에이전트는 **솔루션당 1명** (이미 에이전트가 있으면 생성·지정 **거절**)
   - 구매·판매 권한 토글 · 승인/거절/정지
   - **아이디 클릭** → **회원정보 새창** (`/admin/member/:loginId`) — 탭: 기본정보 · 머니트랜잭션 · 접속기록 · **기본/원화 계좌 섹션 수정·저장**(**활성 계좌 최대 1개**) · 잔고 **USDT 지급/회수** (괄호 KRW는 판매 환율 환산)
   - 연동 **솔루션** 이름 표시 · **기본 지갑 주소(공개키) 클릭** → private key 팝업(관리자만)
2. **계좌 변경 승인** (`/admin/bank-requests`): 우측 상단 **새로고침** · 전체 요청 로드 후 **컬럼 필터**(시각·아이디·이름·은행·계좌·예금주·상태) · 승인/거절(승인 시 기존 활성 계좌는 비활성, **회원당 활성 1개**) · **아이디 클릭** → 회원정보 새창
3. **테더지갑** (`/admin/wallets`): 핫/콜드 커스터디 표 · 우측 상단 잔고 새로고침/등록/생성 · OTC 기본 지정 · 지갑 간 이전(출금≠입금, 필드 좌측 정렬) · 지갑·이전 기록 **컬럼 필터**
4. **OTC 입금·지급** (`/admin/holds`)
   - 목록: 요청자 아이디 · 솔루션 · 원화 계좌 · 금액/상태 · **아이디 클릭** → 회원정보 새창
   - 구매: **KRW 확인·USDT 지급** (장부)
   - 환전(판매): **환전 정산(장부)** — USDT는 주문 시 이미 홀드됨. 원화는 오프라인 지급
   - 각 컬럼 위 필터(유형·거래 ID·상태·KRW/USDT 입금 상태 등)
5. **트랜잭션** (`/admin/transactions`): 전체 로드 + **컬럼 필터**(시각·아이디·자산·방향·금액·잔액·ref) · 방향 표시 **입금/출금** · **아이디 클릭** → 회원정보 새창 · `?loginId=` 딥링크
   - 잔고 **USDT 지급/회수**는 회원정보 새창 잔고 섹션에서 처리 (페이지 내 수동 조정 폼 없음)
6. **에이전트 수수료** (`/admin/agent-fees`): 솔루션별 플랫폼 수수료(%) — 에이전트 지급 = 구매 완료 KRW × (1−%/100) · 상부 표시 · **컬럼 필터**
7. **에이전트 트리** (`/admin/agent-tree`): 솔루션 상부·하부 지정 (하부 수수료% ≥ 상부). 하부 실적 수수료 풀에서 상부가 본인 요율만큼, 나머지는 관리자
8. **에이전트 통계** (`/admin/agent-stats`): 기간별 솔루션 입금·에이전트 지급·상부 차등·관리자 몫 · **컬럼 필터**
9. **에이전트 정산** (`/admin/agent-settlements`): 기간 선택 → 미리보기(상부 차등·관리자 수수료 포함) → **정산 완료** · 미리보기 거래·이력 **컬럼 필터** · 미리보기 **아이디 클릭** → 회원정보 새창 · 기간 표시는 시작일 다음 줄에 `~ 종료`(우측 정렬)
10. **환율** (`/admin/rates`): 시세 소스 **표** · 선택 소스는 액션란에 **선택됨** 표기 · 갱신 주기 · 구매/판매 수수료(%) · 섹션은 가로 구분선만
11. **API 안내** (`/admin/api-guide`): 솔루션 Partner API 연동 안내(한국어)
12. **API 키 관리** (`/admin/solution-keys`): 솔루션 등록 · **공개키·개인키** 발급/재발급/회수 · 활성/비활성. 개인키 = 솔루션 `TPS_PARTNER_KEY` (`X-Partner-Key`)
13. **사이트 설정** (`/admin/settings`)
   - 브라우저 중복 로그인 허용 여부
   - **OTC 알림**: 알림음 ON/OFF · 음색 · 음량(0–100%) · 반복 횟수(1–10) · 테스트 재생 (브라우저 로컬 저장)
   - 최상단 헤더(브랜드 옆)에 **승인 대기 N건** · **커스터디 보유 USDT**(괄호 KRW 환산) · **금일 입금(KRW, KST)** · **수익(솔루션 수수료 합, KST)** · 신규 요청 시 알림음(약 8초 폴링)

## 에이전트 업무 (`/agent`)

1. `/login` → 역할이 `agent`이면 `/agent`로 이동  
   - 관리자는 `/admin-login`에서 비밀번호와 **자동 접속 방지 문자**를 함께 입력  
   - 최상단 헤더: **보유 테더**(괄호 KRW 환산) · **금일 입금**(본인 솔루션, 오늘 KST 완료 구매 KRW 합)  
   - 홈: **본인 솔루션** 유저 입금 일별 시계열 차트 · 기간 **1일/1주(기본)/1개월/3개월**
2. **개인 거래** (내비 그룹): 테더지갑 · 내 정보 · 구매 · 판매 · 전송 · 내 거래 · 거래 내역(`/agent/my-transactions`)  
   - 구매/판매 권한이 꺼져 있으면 탭은 보이지만, 클릭 시 **관리자에게 권한 요청** 안내  
3. **솔루션 관리** (내비 그룹): 솔루션 트랜잭션 · 회원 · 정산  
4. **솔루션 트랜잭션**: 담당 솔루션 회원 USDT·KRW 내역 · **컬럼 필터** · **아이디 클릭** → 회원정보 새창 · `?loginId=` 딥링크  
5. **회원**: 담당 솔루션 회원 목록 · **컬럼 필터** · **아이디/트랜잭션** → 회원정보 새창 (`/agent/member/:loginId`)  
6. **정산**: 미정산 입금·본인 받을 금액 · **하부에서 받을 차등** · 합계 · 정산/차등 이력 **컬럼 필터**  
7. 다른 솔루션·관리자 OTC·키 조회는 **불가**  
   - 회원정보 새창 탭: **기본정보** · **머니트랜잭션** · **접속기록**(로그인·핸드오프, 적용 이후부터 기록)

## 회원 업무 (`/app`)

1. S01 등에서 연동 로그인(핸드오프) 또는 `/login` → 기본 **테더지갑** (`/app/wallets`)
   - 사이드바 하단: **아이디** 오른쪽에 상태 뱃지(`active` 등) · 로그아웃
2. **테더지갑** (`/app/wallets`): USDT 잔고 (외부 출금은 전송 탭)
3. **테더 구매** (`/app/buy`) — 권한 없으면 관리자 권한 요청 안내
   - 입력: 위칸 **낼 금액(원화 입금)** · 아래칸 **받을 금액(테더 수령)**. 어느 칸이든 입력하면 반대가 환율로 계산됨
   - 퀵 추가: 원화 `+1만` 등 · 테더 `+10` 등 (해당 칸에 더함)
   - 적용 환율: 두 칸 사이 `1 테더 ≈ n원` · 기준 사이트 · 시각 · 업데이트 주기
   - 구매 원화는 **원 단위(정수)**만
   - USDT는 환율 환산 후 **소수 둘째 자리 내림**(조금 덜 지급될 수 있음)
   - 주문 버튼에 양쪽 금액 표시 · 관리자 원화 계좌 입금 → 관리자 KRW 확인 후 장부 USDT 반영
4. **테더 판매(환전)** (`/app/sell`) — 권한 없으면 관리자 권한 요청 안내
   - 입력: 위칸 **낼 금액(테더 매도)** · 아래칸 **받을 금액(원화 수령)**. 보유 USDT·**전액**은 위칸
   - 퀵 추가: 테더 `+10` 등 · 원화 `+1만` 등
   - 적용 환율: 두 칸 사이 `1 테더 ≈ n원` · 기준 사이트 · 시각 · 업데이트 주기
   - 지급 원화는 **원 단위(정수)** — `floor(USDT×환율)` (소수 원 없음)
   - USDT 홀드 → 관리자 장부 정산(콜드 지갑 있으면 온체인 스윕) → 원화는 등록 통장으로 오프라인 지급
5. **테더 전송** (`/app/transfer`): 회원 아이디=장부 · 외부 T주소=온체인 · S01 핸드오프 시 **게임 충전** · USDT 수량 입력 아래 **판매 환율 기준 원화(≈ N원)** 표시
6. **내 거래** / **거래 내역**: **컬럼 필터**(유형·상태·ID / 구분·금액 등) · **내 거래** 상태는 목록(select) 선택 · ID 클릭·채팅 없음
7. **내 정보** (`/app/me`): 아이디·이름 · **원화 계좌** 등록 요청·승인 대기 취소·**삭제**(DB는 `deleted` 표시만, 행 유지) · 계좌 **컬럼 필터**  
   - 예전 `/app/banks`는 내 정보로 이동 · 사이드 메뉴 **맨 아래**
